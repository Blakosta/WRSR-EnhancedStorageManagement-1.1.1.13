# WRSR Enhanced Storage Management — адаптация для 1.2.0.8

Отдельная ветка портирования Enhanced Storage Management для Workers & Resources: Soviet Republic 1.2.0.8. Исходная ветка адаптации 1.1.1.13 и `main` не изменяются.

## Статус

- Оригинальный upstream: [Ultimate-Universe/WRSR-EnhancedStorageManagement](https://github.com/Ultimate-Universe/WRSR-EnhancedStorageManagement)
- Исходная версия upstream: игра 1.1.1.9
- Целевая версия этой ветки: игра 1.2.0.8
- Получены и проанализированы целевые `SOVIET64.exe` и `C3DDLL64.dll`.
- Перенесены подтверждённые игровые хуки и поля структур. Временные результаты запроса добавляются через проверенный native `std::vector<uint64_t>::push_back`; позиции зданий читаются из C3D instance records. Нативная зелёная подсветка пока отключена fail-closed.
- Подробности и SHA-256 бинарников: [docs/BINARY_ANALYSIS_1.2.0.8.md](docs/BINARY_ANALYSIS_1.2.0.8.md).
- Windows-сборка запускается автоматически через GitHub Actions при каждом push в эту ветку; результат публикуется как artifact `EnhancedStorageManagement-WRSR-1.2.0.8-candidate`.
- Сборка и проверка в игре ещё не выполнены; это рабочая адаптация, не релиз.

## Принципы

- Сохранять исходную функциональность upstream.
- Не добавлять новые типы соединений, ресурсов или правила передачи.
- Не менять нативную авторизацию передачи, распределение и сохранения игры.
- Переносить только адреса и поля, подтверждённые по бинарникам 1.2.0.8.
- Проверять передачу грузов, отображение запасов, соединения и зелёную подсветку отдельно.
